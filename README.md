
# EcoRuta App

Sistema inteligente de gestión de residuos y rutas de recolección.

## Descripción
EcoRuta es una aplicación que busca facilitar la gestión de residuos mediante una plataforma que conecte a ciudadanos, recolectores y administradores.

## Objetivos
- Facilitar el reporte de residuos.
- Gestionar solicitudes de recolección.
- Organizar rutas de recogida.
- Consultar el estado de los reportes.
- Mejorar la coordinación de los servicios de recolección.

## Módulos principales
1. Gestión de usuarios.
2. Reportes de residuos.
3. Gestión de recolección.
4. Planificación de rutas.
5. Panel administrativo.

## Estructura del proyecto

- frontend/: interfaz de usuario.
- backend/: lógica del sistema y API.
- database/: base de datos.
- docs/: documentación.
